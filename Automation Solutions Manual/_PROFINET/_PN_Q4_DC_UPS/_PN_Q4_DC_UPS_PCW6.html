Startup instructions

View: IEC Programming workspace. Create an instance of function block and add variables to the inputs/outputs/inouts. For read/write parameters set dwNodeID to NodeID value of UPS slot 1 or slot 2..6 for battery parameter. In this example the NodeID is 188dec = BChex.

To read parameters from the UPS choose variable from the parameter list and set wIndex to the related index. Set iReceiveLength to the related size of the variable, to read blockwise enter the required size in BYTE. A rising trigger at xReceive starts the reading process, xBusy is TRUE until the reading process is done. arrReceiveBuffer contains the received data from the UPS. To send parameters to the UPS copy the new values into the arrSendBuffer. Define wIndex and iSendLength like described for reading process. A rising trigger at xSend starts the writing process, xBusy is TRUE until the writing process is done.

Startup instructions
View: IEC Programming workspace.
Create an instance of function block and activate the function block by setting the connected variable to TRUE. The function block collects diagnosis and process alarms from all QUINT4 DC UPS devices in the network and provides the states as an alarm flag (xDiagnosisAlarm, xProcessAlarm) and as readable text (arrAlarmInfo).
