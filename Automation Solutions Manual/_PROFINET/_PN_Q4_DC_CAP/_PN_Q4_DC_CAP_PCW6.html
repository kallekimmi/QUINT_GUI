Function Block PS_Q4_DcCapPN_Param

This block enables acyclic access to parameters of the CAP module, this can be read or write access.
|


















|

Startup instructions

View: IEC Programming workspace.
Create an instance of function block and add variables to the inputs/outputs/inouts. For read/write parameters set dwNodeID to NodeID value of CAP slot 1. In this example the NodeID is 620[dec] = 26C[hex].

To read parameters from the CAP choose variable from the parameter list and set “wIndex” to the related index. Set “iReceiveLength” to the related size of the variable in BYTE. A rising trigger at “xReceive” starts the reading process, “xBusy” is TRUE until the reading process is done. “arrReceiveBuffer” contains the received data from the CAP. To send parameters to the CAP copy the new values into the “arrSendBuffer”. Define “wIndex” and “iSendLength” like described for reading process. A rising trigger at “xSend” starts the writing process, “xBusy” is TRUE until the writing process is done.

This function block receives and decodes alarms of connected CAP modules.
|













|

Name

Type

Description

BOOL

TRUE: activates the Function Block

BOOL

xReset

BOOL

Rising edge: All error messages are deleted. The function block is re-initialized.

Name

Type

Description

Description

16#8000

16#0000_0000

The function block is active.

16#C520

16#xxxx_xxxx

Startup instructions
View: IEC Programming workspace.
Create an instance of function block and activate the function block by setting the connected variable to TRUE. The function block collects diagnosis and process alarms from all QUINT4 CAP 16kJ devices in the network and provides the states as an alarm flag (xDiagnosisAlarm, xProcessAlarm) and as readable text (arrAlarmInfo).
