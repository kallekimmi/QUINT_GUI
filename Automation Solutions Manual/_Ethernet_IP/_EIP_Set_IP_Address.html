Set an IP address

For this example the Rockwell Automation Tool “BOOTP/DHCP Server” is used. The UPS sends BOOTP requests with its MAC Address. Double click on the respective MAC address and set an IP address.
|






















|

If a static IP is needed select the UPS in the relation list below and click on “Disable BOOTP/DHCP”. Please make sure that the IP address of the PC is in the same range as the UPS.
