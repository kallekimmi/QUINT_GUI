There are two ways to set up the hardware configuration. First way is to scan the network for devices.

Startup instructions

Open Main program in the project tree on the left and insert a new box.
|



























|

Select the “PS_Q4_DcUpsEC_Cyclic” function block in the Input assistant and insert it into the Main program by clicking “OK”.
|

































|

Connect needed variables to the in- and outputs of the function block. Make sure that the connected variable at “arrInputPD” has the extension “AT %I*” otherwise it won’t be available as a variable for connecting to the process data of the UPS.
|


























|

Select all PDOs in the hardware configuration of the UPS on the left side, right click on selection and click “Change Multi Link”.
|


























|

Choose the previously defined variable of your Main program for connecting the process data of the UPS with you program. If the variable does not show up in the left window set “All types” on the right side to make it visible.
|























|

Afterwards compile and download the project to the PLC. After activating the function block via “xActivate” the cyclic values of the UPS are shown at the outputs of the function block.

Function block PS_Q4_DcUpsEC_Param

Function block reads/writes parameter from/to the QUINT4 DC UPS.


















|

Description

uintSlaveAddr

UINT

wIndex

WORD

Address of parameter for reading/writing

xReceive

BOOL

Rising edge: Receive data from parameter “wIndex” with length of “udintReceiveLength”

udintReceiveLength

UDINT

Number of receiving bytes

tTimeOutReading

TIME

Timeout for reading parameter. Default: t#500ms

xSend

BOOL
