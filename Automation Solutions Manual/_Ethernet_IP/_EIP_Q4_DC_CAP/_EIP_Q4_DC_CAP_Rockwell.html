Rockwell Automation Studio 5000

Import EDS File

Import the EDS Files with “EDS Hardware Installation Tool”.
|


















|

Navigate through the Installation Wizard and Register an EDS File(s).
|



















|

Select “Register a single file” and browse to the folder which contains the EDS File. Follow the next steps for installing the files.
|























|

Hardware Configuration

There are two ways to configure the hardware. First way is to discover the modules. For this connect to the CAP module and right click on the Ethernet Connection of the PLC. Choose “Discover Modules” and scan the network for the CAP module.
|




































|

Select the previously set IP address and check if the shown Ordernumber matches to the CAP. Click on “Create” and add the CAP to the Hardware configuration.
|

<picture>








|

Name the CAP “QUINT4_CAP_20_16kJ”, enter the previously set address of the CAP.
|

























|

Second way to configure the hardware is to add the CAP with the module catalog. Right click on Ethernet Connection and select “New Module”.
|












|

Search for the correct QUINT4 CAP 16kJ and click on “Create”.
|


























|

Name the CAP “QUINT4_CAP_20_16kJ” and configure the previously set IP address.
|

























|

Software Configuration

AddOn Instruction PS_Q4_DcCapEIP_Implicit

This AddOn Instruction decodes cyclically transmitted data of the UPS and provides them to the user in a readable form.

Startup instructions

Open the “MainRoutine” or a Subroutine. Right click on the routine and select “Import Rungs”.
|


























|

Navigate to the downloaded AddOn Instruction and import the “.L5X file.
|



















|

After successfully imported the rung the AOI should appear like shown below. The preconfigured “InputDataCAP” is set to the Name “QUINT4_CAP_20_16kJ”. It should match to the Name of the CAP which was set in the Hardware configuration.
|





















|

Compile the project and download it on the PLC. After running the system the current values of the CAP are shown in the output structure “CAP_DataStruct”.
